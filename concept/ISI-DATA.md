# Data yang perlu diisi tim Infinity

Semua bagian yang masih kosong tampil di halaman sebagai **kotak bergaris oranye** (kelas `ph`).
Cari `class="ph"` di file HTML untuk menemukannya. Setelah diisi, hapus pembungkus `<span class="ph">…</span>`.

## Pengaturan (`site.js`, bagian paling atas)

- [ ] `WA_NUMBER`: nomor WhatsApp admin, format `62812xxxxxxx`. Selama kosong, semua tombol chat menelepon 021-22733744.
- [ ] `VIDEOS.*.url`: link video yang sudah dikompres (mis. diunggah ke Cloudinary). File mentahnya 90–157 MB per video, terlalu berat untuk HP.
- [ ] `QUESTIONS`: 5 soal TIU contoh. Mohon dicek ulang oleh tentor.

## Beranda (`index.html`)

- [ ] Hasil: jumlah siswa yang lulus pada seleksi terakhir dan jumlah peserta program.
- [ ] Hasil: 4 alumni (nama, prodi, angkatan, asal kota) dan **foto baru beresolusi tinggi**. Foto yang sekarang hanya ±250 px.
- [ ] Program: harga, durasi, dan jumlah pertemuan untuk Reguler, Karantina, dan Kelas di kotamu.
- [ ] Program: ada kelas online atau tidak.
- [ ] Tempat: jam buka.
- [ ] Jalur seleksi: tanggal resmi setiap tahap (isi setelah ada pengumuman resmi).
- [ ] Tanya jawab: profil tentor, syarat "Real Garansi 100%", cicilan, kapan sebaiknya mulai.
- [ ] Footer: link Instagram.

## Tentang (`tentang.html`)

- [ ] Perjalanan 2019–2026. Tanpa ini, kesannya Infinity berhenti di 2018.
- [ ] Susunan manajemen: pastikan masih berlaku.
- [ ] Kota cabang: tandai yang masih aktif tahun ini.
